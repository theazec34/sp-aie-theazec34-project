# Web Accessibility

## When to use
Use this skill when editing public pages such as:
- Home page and menu sections.
- Booking/application forms.
- Mobile navigation and overlays.

## Goals
- Improve keyboard and screen reader support.
- Keep semantic structure and clear landmarks.
- Ensure visible focus states and valid labels.

## Workflow
1. Validate semantic structure (header/main/nav/footer/sections).
2. Check links and button labels for intent clarity.
3. Ensure form inputs have labels, errors and aria attributes.
4. Verify keyboard navigation and focus order.
5. Confirm color contrast in key UI controls.

## Output expected
- Accessibility issues list by severity.
- Concrete code fixes in HTML/CSS/JS.
- Quick manual QA notes (desktop and mobile).
